# Results Viewer

This feature provides a CSV viewer built on AG Grid. Load a local file or remote URL and explore the data with sorting, filtering and column layout persistence.

## Features
- Load local or HTTP CSV files
- Save/restore column layout per file
- Optional pivot for variant catalogs
- Join reference player data
- Summary stats for projections
- Export current view to CSV

## Usage
1. Navigate to `/results`.
2. Load a CSV via file picker or HTTP path.
3. Adjust columns and click **Save View** to persist layout.
4. Use **Add Reference** to enrich variant files with player names.
5. Toggle **Raw/Pivot** for variant files.
6. When viewing projections, review the stats band above the grid.
7. Use **Export** to download the current view.
